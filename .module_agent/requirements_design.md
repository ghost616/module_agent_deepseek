# 需求设计

## 项目概述
本工程将 opencode 开发的「风后力牧」多智能体协同框架插件，按照 DeepSeek Harness（dsh）的规范进行功能复制/移植，使其成为符合 dsh「一切皆插件」Cordis 架构的插件。

## 参考来源
- 原插件源码（只读）：E:\open_code_plugin\src —— 提供原有功能语义（模块管理、工作空间、开发计划、力牧/皋陶/离朱/夔多智能体调度、知识库、工具暴露、权限守卫等）
- dsh 框架规范（只读）：E:\deepseek-harness —— 提供插件 API、生命周期、注册机制、Cordis 插件系统等实现规范

## 核心需求
- 按 dsh 插件规范实现插件入口与工具注册
- 移植模块管理与文件定义功能
- 移植工作空间、知识库、纠正记录、模型配置
- 移植开发计划、审查与测试流程
- 移植多智能体调度与守卫机制
